Introducción

El control de versiones permite registrar los cambios realizados en un proyecto, consultar versiones anteriores y mantener una copia de respaldo. En el proyecto BICSAN se utilizaron Git para el seguimiento local y GitHub para almacenar el repositorio remoto.

Este documento presenta el estado del repositorio y el procedimiento aplicado para incorporar los entregables. Cada actualización queda identificada mediante un commit y se publica en la rama principal del repositorio.

Procedimiento de control de versiones

  1. Se revisó el estado del repositorio para identificar cambios pendientes. git status
  2. Se agregaron únicamente los archivos correspondientes al entregable. git add entregables/
  3. Se creó un commit con una descripción clara de la actualización. git commit -m "Agrega entregable de control de versiones"
  4. Se publicó la nueva versión en la rama principal de GitHub. git push origin main
  5. Se comprobó que la rama local quedara sincronizada con el repositorio remoto. git status --short --branch

Resultados

  • Los archivos del entregable quedaron registrados en el historial de Git.
  • La versión publicada se encuentra respaldada en GitHub.
  • Cada actualización puede identificarse mediante su commit.
  • Las versiones anteriores pueden consultarse o recuperarse cuando sea necesario.
  • La fuente editable se conserva junto con el PDF para facilitar futuras actualizaciones.

Conclusión

El uso conjunto de Git y GitHub permite organizar el desarrollo del proyecto BICSAN y mantener un historial verificable de sus entregables. Este procedimiento facilita el respaldo de la información, la recuperación de versiones y la publicación ordenada de cada actualización.

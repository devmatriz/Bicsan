02 · Procedimiento

Flujo para cada entregable

Cada nueva versión debe registrarse con un mensaje claro y publicarse en GitHub. La fuente editable se conserva junto con el PDF para facilitar futuras actualizaciones.

  1. Revisar el estado

    git status

  2. Agregar únicamente los archivos del entregable

    git add entregables/

  3. Crear una versión identificable

    git commit -m "Agrega entregable de control de versiones"

  4. Publicar la versión en GitHub

    git push origin main

  5. Comprobar la sincronización

    git status --short --branch

Criterios aplicados

Trazabilidad Cada entrega queda asociada a un commit, una fecha y un autor.
Respaldo La versión publicada permanece almacenada en el repositorio remoto de GitHub.
Recuperación Git permite consultar o recuperar versiones anteriores sin reemplazar el historial.
Reproducibilidad La fuente HTML permite volver a generar el PDF cuando cambie la información.
